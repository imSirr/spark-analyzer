Official platform logos
=======================
Drop a square-ish image here named after the platform and it will appear in the
report header. Accepted formats (tried in this order): .png .jpg .jpeg .webp .svg
Transparent background is NOT required - the image is cropped to a uniform
rounded square automatically. If no file is found, a colored badge is shown.

Filenames:
  paper        purpur      pufferfish   folia
  spigot       craftbukkit fabric       quilt
  forge        neoforge    proxy        hybrid

e.g. forge.jpg, paper.png, fabric.png, neoforge.png, spigot.png
